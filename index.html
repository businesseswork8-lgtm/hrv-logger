Shortcut setup once only

1
Delete your existing "Log HRV" shortcut — we need to rebuild it to support date+time
2
Open Shortcuts → + → Add Action → search Split Text → add it → set Separator to Custom → type | → input = Shortcut Input
3
Add Get Item from List → First Item → rename variable to HRVValue
4
Add Get Item from List again → Item at Index 2 → rename to Timestamp
5
Add Date action → tap the date field → choose Variable → pick Timestamp → rename result to EntryDate
6
Add Log Health Sample → type = Heart Rate Variability → value = HRVValue → set date field to EntryDate
7
Name it exactly Log HRV → Done → run once and tap Allow for Apple Health
